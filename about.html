About Forza Gaming

A front-end portfolio project built as a full gaming media site.

What this is

Forza Gaming is a demonstration project: a complete gaming news and community portal built with HTML5, CSS3, vanilla JavaScript and Bootstrap 5. There is no backend, no database and no build step. Every page is a static file you can open directly in a browser or host on GitHub Pages or Vercel.

All games, articles, reviews, tournaments and members are fictional sample data stored in js/data.js. Any resemblance to real products is coincidental.

How the demo features work

  • Sign in and register — accounts are written to localStorage in this browser. No password is ever sent anywhere, and none of it is secure. It exists to show the signed-in interface.
  • Favorites and saved articles — kept in localStorage, so they survive a refresh but not a different device.
  • Dashboard and admin panel — read and write the same local demo data. The admin panel has a reset button that restores the seeded records.
  • Search, filters and sorting — run entirely in JavaScript against the in-memory dataset.

Privacy policy

This demo collects nothing. There is no analytics script, no cookie banner and no server to send data to. Anything you type is stored in your own browser's localStorage and can be removed by clearing site data for this domain.

Terms

The project is provided as-is for portfolio and educational use. Sample imagery is served from picsum.photos. Bootstrap and Bootstrap Icons are used under the MIT licence. Do not reuse the demo authentication pattern in a real product: it stores passwords in plain text on purpose, because nothing here is real.
